# PocketWise | Financial Dashboard

-PocketWise is a simple personal finance web app that helps you manage your money wisely.

-Track your income, expenses, and balance in Kenyan Shillings (KSh), add       transactions, and view financial reports — all in one dashboard.

## Features
- *Financial Dashboard*
    - Total Balance
    - Total Income
    - Total Expenses
    - All displayed in KSh

- *Transactions*
    - Add a new transaction with the + Add Transaction button
    - View Recent Transactions
    - Separate income and expenses

- *Reports*
    - Financial Reports section
    - Summary of your money activity

- *Navigation*
    - Dashboard
    - Transactions
    - Reports
